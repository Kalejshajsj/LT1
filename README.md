# Circular Garden Info Calculator
This program lets you calculate the circumference, area, and everything else using the math library.

## How to run: 
You input the radius and the program calculates the circumference, area, and the square root of the area and also the area rounded up and down. The output is rounded up to 2 decimal places.

## Input/s Needed:

- radius

## Sample Output:
    Input: 9
    Area of the Garden: 254.47 square meters
    Circumference of the Garden: 56.55 meters
    Square root of the area: 15.95
    Area rounded up: 254
    Area rounded down: 255
